# Calibration Data

Assets used by `ai_model/scripts/validate_checkpoint.py` (step 5) to compare a
candidate checkpoint against the baseline before it is allowed into production.

---

## Important: `known_sar_spill.jpg` is not SAR imagery

The file `known_sar_spill.jpg`, described in `ai_model/README.md` and the root
`README.md` as *"Ground-truth SAR image with confirmed oil slick for calibration"*,
is **digital artwork of a person's head**. It is not a Sentinel-1 scene, it contains
no oil slick, and it has no ground truth.

Two things followed from that, both now fixed:

1. **The Layer 1 domain gate accepted it as genuine SAR.** The gate tested channel
   decorrelation and zero-variance blocks only, and a near-greyscale artwork
   satisfies both. It now also tests for speckle — the defining property of a
   coherent radar image — and rejects the file.

2. **The model hot-swap validation gate was benchmarking checkpoints against it.**
   Step 5 of `validate_checkpoint.py` loaded this file for its side-by-side
   behavioural comparison, so every checkpoint that "passed validation" had been
   compared on a drawing. The gate now verifies that its calibration asset is
   admissible SAR before using it, and fails loudly when none is.

The file is deliberately left in place rather than deleted, so that the regression
test in `backend/tests/golden/test_golden_sar_gate.py` (case 5) can keep proving the
domain gate rejects it.

## `synthetic_sar_calibration.png`

A replacement generated by `make_calibration_scene.py`. Synthetic, but statistically
faithful, and — unlike the file it replaces — it comes with a known answer:

| Property | Value |
|---|---|
| Speckle | Multiplicative gamma, 4-look (local CV ≈ 0.5) |
| Brightness | Cross-swath incidence-angle gradient, as a Sentinel-1 GRD has |
| Slick | Elongated along a simulated vessel track, damped in both mean **and** speckle variance |
| Look-alike | A calm-wind patch: equally dark, speckle **not** damped |
| Ground truth | `synthetic_sar_calibration_truth.png` |
| Seed | 26143, so the scene is reproducible |

The look-alike patch is the point. A model that simply finds dark regions will flag
both; only a discriminator that measures speckle damping separates them. That is the
property the calibration gate should be testing for.

Regenerate with:

```bash
python ai_model/calibration_data/make_calibration_scene.py
```

### Caveat that must travel with any result from this file

Synthetic data is a stand-in, not a substitute. Detection scores measured on this
scene describe behaviour on a physically plausible simulation and **must not be
presented as performance on real Sentinel-1 imagery**. The correct fix is a real
scene with a verified slick, for example from the Copernicus Open Access Hub or the
CleanSeaNet archive, with its mask checked by hand.
